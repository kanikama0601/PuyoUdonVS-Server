# ぷようどんVS サーバー

「ぷようどんVS」のネットワーク対戦用サーバーです（VB.NET / .NET 10 のコンソールアプリ）。
企画書「6.4 プロトコル設計」に従い、`ws://<IP>:<ポート>/udon` で WebSocket 接続を受け付けて、ルーム管理・対戦の開始と勝敗の確定・おじゃまそばの計算・メッセージの中継を行います。

## 動かし方

```
dotnet run --project PuyoUdonVS-Server
```

| 引数 | 内容 |
| --- | --- |
| `ポート番号` | 待ち受けるポート（既定 8080）。例: `dotnet run --project PuyoUdonVS-Server -- 9000` |
| `--bind <IP>` | 待ち受けるIP（既定 `0.0.0.0` = すべてのアダプター） |
| `--verbose` | PIECE / STATE / PING など頻繁なメッセージも表示する |

起動すると、最初にこのPCの IPアドレス・ポート番号・接続先URL を表示します。クライアントのタイトル画面にその IPアドレス とポート番号を入力してください。
別のPCから接続できないときは、Windows ファイアウォールでこのポートの受信を許可してください（初回起動時の確認ダイアログで「許可」を選びます）。

## 動作

- ルームIDを指定した JOIN はそのルームへ、空文字なら自動マッチング（`auto-1`, `auto-2` …）へ入ります。2人そろうと両者に同じ `seed` で START を送ります。
- おじゃまそばの数 = 消去数 × 連鎖数 ÷ 2（切り捨て、最低1個）。
- 両者が REMATCH を送ると新しい seed で再戦します。
- どちらかが LEAVE / 切断すると、相手に OPP_LEFT（対戦中なら RESULT `reason:"left"` も）を送り、ルームを解散します（再戦はできません）。
- 15秒間なにも受信しない接続は切断とみなします。
- 形式の誤ったメッセージや状態に合わないメッセージには ERROR（1001〜1004）を返して無視します。

## 構成

| ファイル | 内容 |
| --- | --- |
| `Program.vb` | 起動・引数・起動時の表示・WebSocket の受け付け（Kestrel） |
| `ClientConnection.vb` | 1接続ぶんの受信ループ・送信キュー・タイムアウト監視 |
| `Lobby.vb` | 各メッセージの処理とルーム管理 |
| `Room.vb` | ルーム（2人分の枠と対戦状態） |
| `Protocol.vb` | 定数・エラーコード・JSON の組み立てと読み取り |
| `ServerLog.vb` | 時刻・色付きのログ出力 |
